# 🛡️ Projeto Prático: Framework Integrado de GRC (LGPD, ISO 27001 e ISO 42001)

Este projeto prático consolida a aplicação dos requisitos da **Lei Geral de Proteção de Dados (LGPD)**, integrando-os com as melhores práticas internacionais de Segurança da Informação (**ISO/IEC 27001**) e Governança de Inteligência Artificial (**ISO/IEC 42001**).

O objetivo é simular a atuação real de um profissional de GRC (Governança, Riscos e Conformidade) na estruturação de um programa de privacidade robusto, transparente e auditável.

---

## 🗺️ Trilha de Implementação e Módulos

O framework está dividido em 4 módulos fundamentais de governança. Acesse cada um para verificar os objetivos e entregáveis específicos:

* [📂 Módulo 01: Mapeamento de Dados e Inventário (RoPA)](./01-mapeamento-e-inventario/README.md)
  * Mapeamento de fluxos, matriz de classificação de dados e ciclo de vida de ativos.
* [📂 Módulo 02: Segurança da Informação e Controles (ISO 27001)](./02-seguranca-e-controles-iso27001/README.md)
  * Controle de acesso baseado no menor privilégio, criptografia e vulnerabilidades.
* [📂 Módulo 03: Governança de Inteligência Artificial (ISO 42001)](<./03-govenanca-ia-iso42001/README.md>)
  * Avaliação de impacto de IA (AIIA), explicabilidade e mitigação de vieses algorítmicos.
* [📂 Módulo 04: Gestão de Riscos e Resposta a Incidentes](./04-gestao-de-riscos-incidentes/README.md)
  * Elaboração de RIPD/DPIA e estruturação do plano de contenção de vazamentos.

---

## 🏢 O Grande Cenário Prático (Estudo de Caso Final)

Para consolidar todos os conhecimentos, o projeto adota o cenário de uma instituição fictícia de grande porte que utiliza sistemas automatizados e tratamento massivo de dados sensíveis.
