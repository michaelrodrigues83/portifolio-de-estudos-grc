# 📂 Módulo 01: Mapeamento de Dados e Inventário de Atividades (RoPA)

Neste módulo, estruturamos o inventário de operações de tratamento de dados pessoais (Registro de Operações de Tratamento - RoPA), mapeando o ciclo de vida dos dados desde a coleta até o descarte definitivo.

## 🎯 Objetivos de Conformidade
* **LGPD:** Atendimento ao Artigo 37 (obrigação de manter o registro das operações).
* **ISO 27001:** Alinhamento com o controle de Inventário de Ativos e Manipulação de Ativos.

## 📑 Entregáveis do Módulo
* [ ] **Inventário de Dados de RH (Cenário Prático):** Mapeamento do fluxo de contratação de colaboradores.
* [ ] **Matriz de Classificação de Dados:** Definição de dados públicos, internos, confidenciais e sensíveis.
* [ ] **Mapeamento do Ciclo de Vida do Dado:** Determinação dos tempos de retenção baseados em obrigações legais (CLT, Código Civil).
